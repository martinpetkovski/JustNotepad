# JustNotepad

A notepad that opens anything in a blink, from a shopping list to a 10 GB log file.

[Download for Windows](https://github.com/martinpetkovski/JustNotepad/releases/latest/download/JustNotepad-Setup.exe)

Close it whenever you like. Your tabs and notes are right where you left them next time.

Code comes in color, Markdown looks the way it reads, and if you work with Git or Perforce you can see exactly what you changed.

Made by [Martin Petkovski](https://www.najjak.com/)
