# JustNotepad

Just a notepad. Opens any file instantly, even huge ones. No AI, no accounts, no clutter.

[Download for Windows](https://github.com/martinpetkovski/JustNotepad/releases/latest/download/JustNotepad-Setup.exe)

Free. Windows 10 and 11. No admin rights needed.

## What you get

- **Instant**, at any file size
- **Tabs**, and your work comes back after closing, saved or not
- **Syntax highlighting** for 47 languages
- **Light and dark** themes
- **JSON and XML** tree view, **Markdown** preview
- **Git and Perforce**: live diff, history, submit

## First run

Windows may say "Windows protected your PC", because the app is not code-signed. Click **More info**, then **Run anyway**. It only asks once.
